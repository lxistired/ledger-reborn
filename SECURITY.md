# Security reports

The application listens only on the local loopback interface. Persistent accounting files belong in the user's application data directory, not inside the application bundle. Host/Origin checks, write allowlists and read-only book boundaries are part of the public contract.

Use GitHub private vulnerability reporting when available. If an ordinary bug report demonstrates a problem, use a synthetic ledger and redact secrets. Do not attach a real ledger to a public issue. Report the release, platform, reproduction and affected boundary.

This preview is single-user software. Network hosting, shared-machine access controls and unattended production operation are outside its current support scope.
